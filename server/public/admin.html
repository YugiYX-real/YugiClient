Create a cosmetic

A model, a png, and an mcmeta when it moves

One of every kind is worn at a time, so a cape, a pair of wings and a shield are all on the player together and only a second cape takes the first one off.
Save straight out of Blockbench, in whichever format the project uses. A .bbmodel, a Java model .json, a Bedrock geometry .json with its bones and cubes, and an OptiFine .jem are all read, because those four keep their boxes in four different places and a wing arrives as any of them. The boxes are read here in the browser and stored in the small shape the client builds from, so the game never has to understand Blockbench. Set the project to box uv and the piece comes out exactly as you drew it. A piece drawn as several modules, a left wing and a right wing and a harness, can be picked all at once and they are joined into one model. Every module has to be drawn against the same texture sheet, because the piece wears one png. A .gltf or a .glb is taken as well, with one honest caveat: glTF is a triangle mesh and the game builds boxes, so every mesh part comes across as the box it fits inside. A piece built from a handful of parts survives that well, a single sculpted mesh does not.
The texture the model is painted with. Transparency is kept. A cape needs no model at all, just the usual 64x32 sheet. Pick several pngs and they are stacked here into the one tall strip an animation is, in the order they are listed below, so a frame by frame animation needs no image editor. Frames saved at different sizes are fitted onto the largest one rather than refused, sharply where the sizes double and centred where they do not.
Only needed to choose the speed. It is the ordinary Minecraft file, so {"animation":{"frametime":2}} is a complete one. Frames stacked here get one written for them at two ticks a frame, so this can be left empty.
Picking again adds to this list rather than replacing it, so frames can be gathered from several folders. Remove takes one file back out without starting over. Only what is listed here is uploaded.
Preview
Pick a model and a texture to see it before anyone can wear it.
The piece turns on its own and can be dragged with the mouse. The faint figure is a player at true size, drawn to the same pixels the game uses, so how big the piece is and how far it stands off the back are both visible before anybody is given it. It is not Blockbench and is not trying to be: it draws the same boxes with the same texture the game will, with no lighting on them.
A model is worn exactly where it was drawn, hung from the back of the neck, which is the origin in Blockbench. These two nudges are counted in model pixels, sixteen to a block, so two is a small shift and sixteen is a whole block. Draw wings as a complete pair with the mirror box on no.
