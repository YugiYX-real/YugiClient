# Code of conduct

## The short version

Be decent. We are here to build a launcher, not to score points off each other.

## What is expected

- Assume good faith and ask questions before assuming incompetence.
- Critique code and ideas, never people.
- Respect that maintainers and contributors are volunteers with limited time.
- Keep discussion in issues and pull requests on topic and in English so everyone can
  follow along.

## What is not acceptable

- Harassment, insults, or discriminatory language of any kind.
- Sexualised language or imagery, or unwelcome personal attention.
- Publishing other people's private information.
- Deliberately derailing discussions, or sustained bad-faith argument.
- Encouraging or distributing piracy, cracked accounts or malware.

## Scope

This applies to every project space: issues, pull requests, discussions, commit
messages and code review.

## Enforcement

Report problems privately to the maintainer through GitHub. Reports are handled
confidentially. Depending on severity, the response ranges from a warning to a permanent
ban from the project's spaces. Maintainers who do not uphold this document in good faith
should be held to the same standard as anyone else.
